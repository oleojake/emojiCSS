How it works

  1. 1

    Paste a <link>

    One stylesheet. No build step, no PostCSS, no 200-line config file.

  2. 2

    Put an emoji in class

    Use it like a Tailwind utility. class="🔄" makes the element spin.

  3. 3

    Stack as many as you like

    class="🔄 🌈" spins and changes color at the same time.

Why classes stack

Each family of classes animates a different CSS property (rotate, translate, scale, filter…). That's why several emojis on the same element add up instead of overriding each other.

Under the hood, every class fills its own slot, a custom property, and a single rule combines all the slots into one animation.

/* what .🔄 + .🏀 + .💓 generate */
.🔄 { --ec-r: ec-spin 1s linear infinite; }
.🏀 { --ec-t: ec-bounce .9s infinite; }
.💓 { --ec-s: ec-heartbeat 1.2s infinite; }

.🔄, .🏀, .💓, /* …and 63 more */ {
  animation:
    var(--ec-r, none), var(--ec-t, none),
    var(--ec-s, none), var(--ec-f, none),
    var(--ec-o, none), var(--ec-k, none),
    var(--ec-x, none), var(--ec-b, none);
}

What the community says

Frequently asked questions

Is this actually valid CSS?

Yes. CSS identifiers accept any character above U+0080, emojis included, so .🔄 is as legal as .btn. Whether it should exist is a different conversation.

Which browsers support it?

Current versions of Chrome, Edge, Safari and Firefox. Animation composition relies on @property and the individual rotate, translate and scale properties. Internet Explorer? 🪦

Can I combine several classes?

Yes. Classes from different families (rotation, movement, scale…) add up. Within the same family, whichever comes later in the stylesheet wins, like any other CSS. Special effects use ::before and ::after, so you get one per element.

Why won't my <span> move?

Transforms don't apply to inline elements. EmojiCSS already sets display: inline-block on span, a, em and friends when they carry a movement class. If you use another inline tag, add it yourself.

Is it accessible?

We respect prefers-reduced-motion: if your system asks for less motion, everything stays still. It's the only serious part of the project. And please, don't animate text people actually need to read.

Is it production-ready?

Define "production".

Can I use my own emojis?

Yes. Any element can wear emoji classes, including an <img> or a PNG used as a CSS background, and you can define your own emoji classes with their own animation. There's a live example under Real-world examples. To add an emoji to the library itself, add it to src/emojis.mjs, run npm run build and open a PR.
